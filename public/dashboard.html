    Broad WAN-inbound rules

    Enabled custom rules with an unrestricted source in the External zone, allowing any destination port — not scoped to established/related return traffic.

    Port forwards aren't exposed by this API yet — check Settings → Port Forwarding on the console directly (usually a short list).

    Redundant / duplicate rules

    Differently-named rules with identical effect. Rules that share a name are UniFi's own per-zone expansion of one rule, not duplicates — those are excluded.

      Dangling references

        Default zone trust vendor-predefined

        Zone pairs where at least one system-defined rule allows everything by default — not something you configured. A narrower custom rule can still restrict specific traffic within a pair listed here, so treat this as informational, not the final word.
